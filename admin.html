🚀 Deploy This Branding

Saving above applies branding on this device (great for demos and configuring your own instance). To make it permanent for every visitor, add this partner entry to partners.json and deploy.

No backend, no data capture. Branding lives in a static partners.json file plus optional per-device overrides. No customer data is involved.
